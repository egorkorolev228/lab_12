## Что делает
Программа хранит героев игры в файле data.txt:
создаёт объекты класса Hero, сохраняет их и загружает обратно.
Обрабатываются ошибки: деление на ноль, неверный ввод,
отсутствующий файл, неверный формат данных.
 
## Как запустить
python main.py
(На Ubuntu: python3 main.py)
 
## Пример вывода
Герой: Артас, уровень 80, здоровье 2500
Герой: Сильвана, уровень 65, здоровье 1800
